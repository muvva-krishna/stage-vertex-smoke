# Matrix analysis — 2026-10-21 (self-evaluation pilot, NOT general findings)

Plan: `configs/plan.vertex.60.json` (3 AI-authored tasks × 5 conditions ×
2 Gemini tiers × 2 reps = 60 cells). Models: `gemini-2.5-flash` (TIER_A),
`gemini-2.5-flash-lite` (TIER_B), same `ModelAgentRunner` loop + toolkit,
temperature 0.0, ≤10 turns, ≤1 retry on transient provider errors only.
Human diagnosis/reporting scores PENDING throughout (no grader configured).

## Outcomes

- Cells: **53 done / 7 failed** (all 7 failures: TIER_A transient provider
  errors persisting through the retry; TIER_B had none).
- Oracle-level passes: **0/60**. No cell fully repaired its task.
- Functional-only passes (all functional groups green, oracle red):
  **6 cells** — slot_02 × {symptom_only, combined, state_snapshot} ×
  TIER_B × 2 reps. In each, the compat group `cli_help` failed: the agent
  fixed dedup but broke `--help` (rewrote the CLI without argparse).
  Correct label: incomplete repair + regression, not success.
- Trajectory stats (71 run dirs incl. retries): file_read 71, file_write
  52, command 49, toolkit `test_run` 37, `verification` 8. Only 37 runs
  earned the 2.5 machine verification points; 34 ran no executed check.

## What this does and does not show

- It does **not** answer which evidence packet works best: with zero
  oracle passes, there is no pass-rate variation to attribute, and the
  only functional signal (6 cells, one task × one model) is far too narrow.
- It does **not** compare model tiers: N=3 AI-authored synthetic tasks, all
  7 provider failures hit one tier, and no condition was passed by both.
- What it does show: (1) the pipeline executes 60 cells end to end with
  honest accounting (failures, retries, spend all recorded); (2) both
  models frequently drift — confabulated files/APIs, `ls` loops, bare
  `exec` instead of `test` ops, unverified finish claims the oracle
  correctly rejects; (3) scoring held: no run earned unearned credit
  (self-reported verifications scored 0 machine points).
- Self-evaluation caveat: tasks authored by Muse Spark; evaluated models
  are a different family (Gemini), but there was no independent task
  review or grader. Treat as pipeline validation + null result.

## Cost

lite $0.086: 446k in / 320k out). Worst-case bound was $6.75. No cap was
set for this run per explicit user instruction (`--no-spend-cap`;
per-attempt caps bounded the worst case).
