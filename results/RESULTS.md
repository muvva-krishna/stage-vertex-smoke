# Results

Generated by `python3 experiments/staleness_probe.py` (8 paired cases, 72 total trials).

| Evidence condition | Method | Top-1 | Accuracy | MRR |
|---|---|---:|---:|---:|
| Current trace | issue only | 6/8 | 0.750 | 0.833 |
| Current trace | all evidence | 8/8 | 1.000 | 1.000 |
| Current trace | revision gated | 8/8 | 1.000 | 1.000 |
| Stale note only | issue only | 6/8 | 0.750 | 0.833 |
| Stale note only | all evidence | 3/8 | 0.375 | 0.635 |
| Stale note only | revision gated | 6/8 | 0.750 | 0.833 |
| Current + stale | issue only | 6/8 | 0.750 | 0.833 |
| Current + stale | all evidence | 7/8 | 0.875 | 0.938 |
| Current + stale | revision gated | 8/8 | 1.000 | 1.000 |

Relative to the issue-only baseline, unfiltered evidence improved top-1 accuracy by 0.25 on current evidence, reduced it by 0.375 on stale evidence, and improved it by 0.125 when both were present. Revision-gated evidence matched the issue-only baseline under stale-only evidence and scored 0.25 higher when current evidence was present.

These are exact counts on eight designed cases. The result supports only the narrow observation that revision filtering protects this lexical ranker from the stale notes built into this probe. It says nothing about how often stale evidence occurs in production or how a language model would respond.

The per-case ranks and experiment configuration are in [`staleness_probe.json`](staleness_probe.json).
